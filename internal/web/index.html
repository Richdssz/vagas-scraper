⏰ Como Você Deseja Rodar Automaticamente?
Escolha onde o robô deve rodar 3 vezes ao dia de forma 100% autônoma.

O Windows executará o robô 3 vezes ao dia (às 09:00, 14:00 e 19:00). Ele inicia em segundo plano, busca as vagas em 1 segundo, envia o e-mail se houver novidade e desliga imediatamente (0% de CPU no resto do dia).

Não requer que o painel continue aberto.

Você pode subir este repositório para o GitHub e usar o GitHub Actions para rodar 3x ao dia na nuvem (sem precisar do seu computador estar ligado).

1. Vá em Settings -> Secrets and variables -> Actions no seu repositório.
2. Adicione os segredos: EMAIL_REMETENTE, EMAIL_SENHA_APP, EMAIL_DESTINATARIO.
3. O arquivo .github/workflows/scraper.yml já está pronto e agendado com o cron: '0 12,17,22 * * *'
